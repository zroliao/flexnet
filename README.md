# 快速開始

快速在本地運行 P2P 及 WebSocket 範例

```
# 安裝依賴
npm install

# 啟動 Signal Server
npx ts-node samples/example-signal-server.ts

# 啟動 Edge Server
npx ts-node samples/example-edge-server.ts

# 啟動 Web Server
http-server

# 打開瀏覽器執行以下任一範例
http://localhost:8080/samples/index-pp.html
http://localhost:8080/samples/index-ws-subscribe.html
http://localhost:8080/samples/index-ws.html

```
